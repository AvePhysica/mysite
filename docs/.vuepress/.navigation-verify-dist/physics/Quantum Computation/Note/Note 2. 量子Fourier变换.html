本章介绍量子傅里叶变换(Quantum Fourier Transformation, QFT)

基本概念与量子线路实现

我们已经很熟悉连续傅里叶变换，其一种版本可以表述为：

F(y)=∫−∞∞f(x) e2πixy dx,f(x)=∫−∞∞F(y) e−2πixy dyF(y)=\int_{-\infty}^{\infty}f(x)\,\mathrm{e}^{2\pi ixy}\,\mathrm{d}x,\quad f(x)=\int_{-\infty}^\infty F(y)\,\mathrm{e}^{-2\pi ixy}\,\mathrm{d}y F(y)=∫−∞∞​f(x)e2πixydx,f(x)=∫−∞∞​F(y)e−2πixydy

离散傅里叶变换只需将上面的积分改为求和。NNN 个离散数的傅里叶变换可以表述为：

yk=1N∑j=0N−1xj e2πijkN,xj=1N∑k=0N−1yk e−2πijkNy_k=\dfrac{1}{\sqrt N}\sum_{j=0}^{N-1}x_j\,\mathrm{e}^{2\pi i\frac{jk}{N}},\quad x_j=\dfrac{1}{\sqrt N}\sum_{k=0}^{N-1}y_k\,\mathrm{e}^{-2\pi i\frac{jk}{N}} yk​=N​1​j=0∑N−1​xj​e2πiNjk​,xj​=N​1​k=0∑N−1​yk​e−2πiNjk​

量子傅里叶变换(QFT)的作用对象是基矢，例如在 NNN 维空间中，基矢 {∣j⟩}\{|j\rangle\}{∣j⟩} 的量子傅里叶变换为：

∣j⟩→1N∑k=0N−1∣k⟩ e2πijkN|j\rangle\to\dfrac{1}{\sqrt N}\sum_{k=0}^{N-1}|k\rangle\,\mathrm{e}^{2\pi i\frac{jk}{N}} ∣j⟩→N​1​k=0∑N−1​∣k⟩e2πiNjk​

这是一个幺正变换。对于任意态的变换为：

∑j=0N−1xj∣j⟩→∑k=0N−1∣k⟩(1N∑j=0N−1xj e2πijkN)=∑k=0N−1yk∣k⟩\sum_{j=0}^{N-1}x_j|j\rangle\to\sum_{k=0}^{N-1}|k\rangle\left(\dfrac{1}{\sqrt N}\sum_{j=0}^{N-1}x_j\,\mathrm{e}^{2\pi i\frac{jk}{N}}\right)=\sum_{k=0}^{N-1}y_k|k\rangle j=0∑N−1​xj​∣j⟩→k=0∑N−1​∣k⟩(N​1​j=0∑N−1​xj​e2πiNjk​)=k=0∑N−1​yk​∣k⟩

即其相当于对系数做了离散傅里叶变换。

接下来，我们假设 N=2nN=2^nN=2n，即研究n个qubits的变换。系统基矢可用一个二级制数 j=j1⋯jnj=j_1\cdots j_nj=j1​⋯jn​ 表示。此时有下面的结论：

∣j1⋯jn⟩→QFT12n/2(∣0⟩+e2πi 0.jn∣1⟩)(∣0⟩+e2πi 0.jn−1jn∣1⟩)⋯(∣0⟩+e2πi 0.j1j2⋯jn∣1⟩)|j_1\cdots j_n\rangle\xrightarrow{QFT}\dfrac{1}{2^{n/2}}(|0\rangle+\mathrm{e}^{2\pi i\,0.j_n}|1\rangle)(|0\rangle+\mathrm{e}^{2\pi i\,0.j_{n-1}j_n}|1\rangle)\cdots(|0\rangle+\mathrm{e}^{2\pi i\,0.j_1j_2\cdots j_n}|1\rangle) ∣j1​⋯jn​⟩QFT​2n/21​(∣0⟩+e2πi0.jn​∣1⟩)(∣0⟩+e2πi0.jn−1​jn​∣1⟩)⋯(∣0⟩+e2πi0.j1​j2​⋯jn​∣1⟩)

上式称为QFT的乘积表示。直接计算可验证：

∣j1⋯jn⟩→QFT12n/2∑{ki=0,1}e2πij(k12+k222+⋯+kn2n)∣k1⋯kn⟩=12n/2⨂i=1n(∣0⟩+e2πij2i∣1⟩)=12n/2(∣0⟩+e2πi 0.jn∣1⟩)(∣0⟩+e2πi 0.jn−1jn∣1⟩)⋯(∣0⟩+e2πi 0.j1j2⋯jn∣1⟩)\begin{align} |j_1\cdots j_n\rangle\xrightarrow{QFT}\dfrac{1}{2^{n/2}}\sum_{\{k_i=0,1\}}\mathrm{e}^{2\pi ij(\frac{k_1}{2}+\frac{k_2}{2^2}+\cdots+\frac{k_n}{2^n})}|k_1\cdots k_n\rangle=\dfrac{1}{2^{n/2}}\bigotimes_{i=1}^n(|0\rangle+\mathrm{e}^{2\pi i\frac{j}{2^i}}|1\rangle)\\=\dfrac{1}{2^{n/2}}(|0\rangle+\mathrm{e}^{2\pi i\,0.j_n}|1\rangle)(|0\rangle+\mathrm{e}^{2\pi i\,0.j_{n-1}j_n}|1\rangle)\cdots(|0\rangle+\mathrm{e}^{2\pi i\,0.j_1j_2\cdots j_n}|1\rangle) \end{align} ∣j1​⋯jn​⟩QFT​2n/21​{ki​=0,1}∑​e2πij(2k1​​+22k2​​+⋯+2nkn​​)∣k1​⋯kn​⟩=2n/21​i=1⨂n​(∣0⟩+e2πi2ij​∣1⟩)=2n/21​(∣0⟩+e2πi0.jn​∣1⟩)(∣0⟩+e2πi0.jn−1​jn​∣1⟩)⋯(∣0⟩+e2πi0.j1​j2​⋯jn​∣1⟩)​​

接下来，我们自然会考虑如何用量子线路实现QFT。首先的思路是设计线路实现变换：

∣j1⟩→∣0⟩+e2πi 0.jn∣1⟩,⋯ ,∣jn⟩→∣0⟩+e2πi 0.j1⋯jn∣1⟩|j_1\rangle\to|0\rangle+\mathrm{e}^{2\pi i\,0.j_n}|1\rangle,\quad \cdots,\quad |j_n\rangle\to|0\rangle+\mathrm{e}^{2\pi i\,0.j_1\cdots j_n}|1\rangle ∣j1​⟩→∣0⟩+e2πi0.jn​∣1⟩,⋯,∣jn​⟩→∣0⟩+e2πi0.j1​⋯jn​∣1⟩

但这是不行的，因为为了实现 jnj_njn​ 的变换，我们需要使用 ∣j1⟩|j_1\rangle∣j1​⟩，但其已经在第一步中变换掉了。因此，我们需要将整个过程反过来：

∣j1⟩→∣0⟩+e2πi 0.j1⋯jn∣1⟩,⋯ ,∣jn⟩→∣0⟩+e2πi 0.jn∣1⟩|j_1\rangle\to|0\rangle+\mathrm{e}^{2\pi i\,0.j_1\cdots j_n}|1\rangle,\quad \cdots,\quad |j_n\rangle\to|0\rangle+\mathrm{e}^{2\pi i\,0.j_n}|1\rangle ∣j1​⟩→∣0⟩+e2πi0.j1​⋯jn​∣1⟩,⋯,∣jn​⟩→∣0⟩+e2πi0.jn​∣1⟩

这样，后面的变换才不会用到前面的状态。最后我们再做交换运算：

∣j1⟩↔∣jn⟩,∣j2⟩↔∣jn−1⟩,⋯|j_1\rangle\leftrightarrow |j_n\rangle,\quad |j_2\rangle\leftrightarrow |j_{n-1}\rangle,\quad\cdots ∣j1​⟩↔∣jn​⟩,∣j2​⟩↔∣jn−1​⟩,⋯

求阶问题与质因数分解

著名的RSA加密算法的核心在于，经典算法对一个大数分解质因数是困难的。对于分解 N=p×qN=p\times qN=p×q，现在最先进的经典算法完成的时间为：

2(log⁡N)a,a=132^{(\log N)^a},\quad a=\dfrac13 2(logN)a,a=31​

对于量子计算，其按下面的流程进行：

  • 如果 NNN 为偶数，则直接返回2。
  • 确定 NNN 是否可以写为形式 N=abN=a^bN=ab，如果是则返回 aaa。此步可以用经典算法高效完成。
  • 随机选取一个 x∈{2,⋯ ,N−1}x\in\{2,\cdots,N-1\}x∈{2,⋯,N−1}，如果 GCD(x,N)>1\mathrm{GCD}(x,N)>1GCD(x,N)>1 则返回 xxx。
  • 确定最小的 r>0r>0r>0 使得 xr≡1 (mod N)x^r\equiv 1\,(\mathrm{mod}\,N)xr≡1(modN)。
  • 若 rrr 为偶时，计算 GCD(xr/2−1,N)\mathrm{GCD}(x^{r/2}-1,N)GCD(xr/2−1,N) 与 GCD(xr/2+1,N)\mathrm{GCD}(x^{r/2}+1,N)GCD(xr/2+1,N)，检查其中是否包含非平凡结果。如果没有，则返回步骤3。 求最大公约数可以使用经典算法高效完成。因此上面需要量子算法参与的只有步骤4，这一步也称为求阶问题。 求阶问题实际上可以等效为一个相位估计问题。考虑一个幺正算符：
