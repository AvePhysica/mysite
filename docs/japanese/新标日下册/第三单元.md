## Chap.33

**自/他动词**：日语中存在许多有对应关系的自/他动词。
- ある（自）- える（他）
- える（自）- す（他）
- 其他

| 自动词 | 他动词 |
| --- | --- |
| 掛かる | 掛ける |
| 止まる | 止める |
| 閉まる | 閉める |
| 消える | 消す  |
| 壊れる | 壊す  |
| 落ちる | 落とす |
| 割れる | 割る  |
| 付く  | 付ける |

<br>

**そうだ**：前面接动词ます形，形容词与形容动词原形。表示对某种事物样态的观感或对某种情形的推测。
- このケーキはとてもおいしそうです。
- 雨が降りそうです。
否定形：前接动词时为そうではありません，前接形容（动）词时为そうにありません。
- あまりおいしそうではありません。
- 雨はやみそうにありません。
前接ない变成なさそうです，前接いい变为よさそうです。
- 今日は会議がなさそうです。
- この本はとてもよさそうです。
そうだ可视为一种形容动词，连体形为そうな，连用形为そうに。
- おいしそうなケーキですね。
- 子供たちは楽しそうに遊んでいます。

<br>

**それにしても**：“即使这样”，表示认可某前提的状况，但说话人仍然有另外的感受或认识。
- それにしても、大勢並んでいるわね。

<br>

**お元気そうで、何よりです**：“你看上去挺精神的，这比什么都强”。

## Chap.34

**他动词＋てある**：表示有意进行的动作的结果的存续状态。前面接的不是动作的主体，而是动作的对象。
- 窓が開けてあります。
- カレンダーが掛けてあります。

<br>

**动词ておく**：表示为某种准备有意识进行的动作。
- お客さんが来る前に、部屋を掃除しておきます。
- 明日は忙しいです、今夜はゆっくり休んておいてください。

<br>

**动词てみる**：表示尝试做某事。
- 食べてみましょうよ。
- もう一度調べてみてください。

<br>

**小句/名词の＋ために**：表目的。前后小句主语相同。
- 日本に留学ために、お金をためています。
- 留学のために、日本語を勉強しています。

<br>

**とっておきの＋名词**：特意留着的……

## Chap.35

**たら**：表假定条件。前接过去形式的た形。かった $\to$ かったら，だった $\to$ だったら，ではなかった $\to$ でなかったら。
- あしたあめがふったら、大会は中止です。
- 寒かったら、窓が閉めてください。
此外，敬体形ました $\to$ ましたら、でした $\to$ でしたら。形容词不用敬体形。

<br>

**何かあった**：询问“有什么事情发生了吗”。
- 駅前で何かあったんですか。人が集まっていますよ。

<br>

**～のとおりに**：“正如……说的那样”
- 本のとおりに作っても、なかなかうまくないんです。
- 昨日は天気予報の通りに、大雨が降りました。

<br>

**だんだん**：表示事物逐渐发生变化（缓慢）
- 秋になると、紅葉の葉がだんだん赤くなります。

## Chap.36

**に**：表用途、基准。
- この写真は何に使いますか。
- この本は、大人には易しいです。しかし、子供には難しいです。
前面接的名词可以等价改成动词+のに的形式：
- このフライパは卵焼きを作るのに使います。

<br>

**N＋ばかり＋V、V（て）ばかりいます**：ばかり表限定，“只做……”，“总是做……”。
- なんで野菜ばかり食べているんですか。
- 趙さんは毎日お酒を飲んでばかりいます。
だけ也表示限定。区别：ばかり不能前接数字词，不能与否定形式连用，但包含反复做同一动作的意思。

<br>

**连体形（Vる/AIい/AIIな）＋のが＋見えます/聞こえます**：能看到/听到（……动作）
- 空港の入口に警官が立っているのが見えます。
- 隣の部屋で子供たちが騒いでいるの聞こえます。

<br>

**とにかく**：“特别是”。虽然事情很多，但不一一列举而优先陈述某事时使用。
- 間に合うかどうかわかりませんが、とにかく行きましょう。
